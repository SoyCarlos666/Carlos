## 💾 ¿Por qué hay dos formas de guardar?

### Guardar

El botón **GUARDAR** guarda la configuración en `localStorage`.

Eso sirve para conservar tus cambios en el mismo navegador/dispositivo.

### Descargar Config

GitHub Pages es un hosting estático. Un panel HTML no puede modificar directamente el archivo `config.js` que está dentro de tu repositorio.

Por eso el panel tiene:

**DESCARGAR CONFIG**

Después de editar:

1. Pulsa **GUARDAR**.
2. Pulsa **DESCARGAR CONFIG**.
3. Se descargará un nuevo `config.js`.
4. Entra a tu repositorio de GitHub.
5. Reemplaza el `config.js` antiguo por el nuevo.
6. GitHub Pages publicará la nueva configuración.

Así los cambios quedan publicados para todos los visitantes.
