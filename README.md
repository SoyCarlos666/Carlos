# Manager Portfolio — Staff Management

Portafolio profesional para Manager / Staff Manager de Minecraft.

## Archivos

- `index.html` — página pública.
- `style.css` — diseño, responsive y animaciones.
- `script.js` — carga de contenido y efectos.
- `config.js` — configuración inicial.
- `admin.html` — panel visual para editar el portfolio.
- `admin.js` — lógica del panel.

## Cómo usarlo

1. Sube todos los archivos al mismo repositorio.
2. Abre `index.html` para ver el portfolio.
3. Abre `admin.html` para editar nombre, logo, textos, estadísticas, proyectos, referencias, colores, Discord y email.
4. Pulsa **Guardar cambios**.
5. Usa **Exportar** para guardar una copia de tu configuración.

### Importante

El panel usa `localStorage`, por lo que los cambios se guardan en el navegador/dispositivo donde los haces. GitHub Pages es estático y no puede guardar cambios en un servidor por sí solo.

Si quieres que los cambios del panel sean visibles automáticamente para cualquier visitante desde cualquier dispositivo, necesitarías conectar el panel a una base de datos/backend. Esta versión no necesita backend y funciona directamente en GitHub Pages.

Los proyectos incluidos son ejemplos editables desde el panel.
